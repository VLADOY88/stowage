STOWAGE PLAN APP - INSTALL ON IPHONE (one time, needs internet)

1. On a PC, create a free account at github.com.
2. Create a new public repository, e.g. "stowage".
3. Click "uploading an existing file" and drag ALL files from this zip (there are no subfolders). Commit.
4. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
5. After 1-2 minutes the app is at: https://YOUR-USERNAME.github.io/stowage/
6. On the iPhone open that link in Safari > Share > Add to Home Screen.
7. Open the app once from the Home Screen while online. After that it works fully offline.

All data is stored only on the iPhone. Use Export > Save backup file regularly.
Updates: upload changed files to the same repository, then open the app once while online.
